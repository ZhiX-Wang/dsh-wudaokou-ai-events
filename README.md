# 五道口 AI 活动

在 DSH 聊天中查找五道口、清华附近的 AI 线下活动，并补充海淀、中关村的候选。

## 使用

安装并启用后，直接在 DSH 中说：

> 帮我找未来两周五道口附近的 AI 线下活动，列出时间、地点、费用和报名链接。

也可以说：

> 找未来七天清华附近的 Agent 或创业交流活动。
>
> 看看之前搜过哪些活动来源。

## 安装

需要 DeepSeek Harness 0.2.1-rc.2 或兼容的 0.2.1 版本，且已有可用的网页搜索与网页读取服务。已在 macOS 的 DSH 0.2.1-rc.2 中完成安装、启用和真实检索验证；其他系统尚未实机验证。

在“插件 → 已安装 → 添加插件 → 安装第三方插件”中，输入：

```text
https://github.com/ZhiX-Wang/dsh-wudaokou-ai-events
```

也可以在 [Releases](https://github.com/ZhiX-Wang/dsh-wudaokou-ai-events/releases) 下载 `.tgz` 安装包，再将本地文件路径填入安装框。启用插件；若 DSH 提示重启，保存正在进行的任务后重启。

插件包名称：`dsh-wudaokou-ai-events`。卸载或停用可在 DSH 插件页完成。

## 做什么

- 每次调用执行三组实时网页搜索，优先五道口、清华，并搜索海淀、中关村和清华官网。
- 返回最多十二条候选来源，自动尝试读取其中五条正文。
- 让会话模型依据实际文字整理活动信息。网页发布日期与活动日期分开处理。
- 保存最近六十次检索和最多三百条来源，标记首次发现、重复来源和标题或摘要变化。
- 默认查未来十四天，可指定一至三十天，日期按北京时间计算。

## 数据与限制

复用 DSH 的 `ctx.web.search()` 和 `ctx.web.fetch()`；不需要额外 API Key。网页搜索可能使用 DSH 已配置的付费服务，费用按该服务计费。

本地历史存放在 `$DSH_HOME/storages/wudaokou-ai-events/history.json`；未设 `DSH_HOME` 时位于 `~/.dsh/storages/wudaokou-ai-events/history.json`。仅保存公开来源和检索记录，不读取私人聊天、联系方式或课程文件。停用、卸载不删除历史。

检索结果是候选来源。聚合站和活动平台不自动视为主办方原文；正文读取成功也不代表报名仍有效。模型需要从原文核对活动日期、地点、费用、报名入口和审核条件。未确认信息显示为待核实，没有合格活动时应明确说明。

“标题或摘要变化”只表示来源内容有变化，不表示活动改期。重复识别按规范化来源 URL 进行，同一活动的不同发布页可能分别出现。微信公众号、小红书等页面可能无法取得正文，插件会显示读取失败或待核实。

第一版按用户请求查询，不自动推送、不自动报名。

## 开发

无第三方运行依赖。`core.js` 实现检索、正文摘取和历史保存；`index.js` 注册两个模型工具和使用说明；`cordis.patch.yml` 将插件挂载到 DSH。

运行检查：`npm test`。

测试位于源码仓库的 `test/` 目录，发布安装包仅包含运行所需文件。

问题反馈：[GitHub Issues](https://github.com/ZhiX-Wang/dsh-wudaokou-ai-events/issues)。

本插件主要对应“给模型增加连接真实数据源的工具”；同时在模型输入中加入固定的活动整理要求。
